# white-box-caption
gif video meme meme-generator caption gif-editor video-editor ffmpeg pillow tkinter python windows windows-app impact-font youtube-shorts offline desktop-app
## What's new
- Output resolution: Shorts / Reels / TikTok (1080x1920), Square, 4:5, Landscape, or custom width x height
- Fit modes: blurred / black / white bars, crop to fill, or stretch
- Compression presets (Best to Tiny) for video, GIF and JPG

## Notes
- Video needs [ffmpeg](https://www.gyan.dev/ffmpeg/builds/ffmpeg-git-full.7z) (https://www.gyan.dev/ffmpeg/builds/). GIFs and images work out of the box.
- [Python required](https://www.python.org/downloads/) 
- Windows may show a SmartScreen warning because the exe is unsigned. Click "More info" then "Run anyway".
